# Capture

Record a raw idea. The whole job is speed.

## Procedure

1. Scan `thoughts/` for the highest existing number, assign the next `T-<number>`.
2. Create the card file with:
   - `status: seed`, today's date for `created` and `updated`
   - the user's sentence **verbatim** as the quote line
3. If the involved system is obvious (combat, camera, UI...), add one line under Notes. If not obvious, skip it.
4. Reply with one short acknowledgment, e.g. "Noted as T-013." Then stop.

## Forbidden

- Clarifying questions of any kind ("which system?", "what do you mean by...?")
- Suggestions, improvements, enrichment
- Asking the user to fill in any field

The user will often capture mid-flow while doing something else. Any friction here kills the habit.
