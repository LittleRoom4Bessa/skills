# Skills

My agent skills. Anything an agent can load lives here.

## gamedev

An idea-to-production workflow for indie game development, plus the routing rule for when to use a standard spec-driven flow (OpenSpec) instead.

- **game-flow** — router. One question decides the toolkit: *do you know what "done" looks like, or do you need to feel it to know?*
- **thoughts** — zero-friction idea pool. Raw sentence → hypothesis + slice → ripe.
- **prototype** — 2-hour throwaway spike on an `exp/` branch; ends in a keep / iterate / kill verdict.
- **landing** — executes the verdict: clean rewrite preserving feel (with review close-out and OpenSpec handoff for large adoptions), or a graveyard entry with a cause of death.
- **savepoint** — pause/resume any in-progress work with low re-entry cost.

Design notes: human gates at every verdict; friction is spent at the prototype gate, never at idea capture; prototype code never merges into main.
